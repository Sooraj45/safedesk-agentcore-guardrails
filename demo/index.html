    What SafeDesk will not do

    These limits are part of the proposed AgentCore project. This page illustrates them locally.

    01

    Touch production

    No shell, browser, network, or write tools are exposed to the proposed agent.

    02

    Handle secrets

    Credential requests are redirected to an authorized human process.

    03

    Obey ticket instructions

    Instructions pasted into a ticket are treated as untrusted content.

    04

    Claim work was done

    A triage answer never pretends to inspect or change a real system.

    The real project

    Built for review, awaiting a live run.

    The companion source project configures an Amazon Bedrock AgentCore managed harness with a restricted tool allowlist, disabled memory, a triage system prompt, and adversarial test cases. Because no AWS account is being used, the harness has not been deployed or live tested. A Vercel demo alone does not qualify as an AWS hackathon submission.
